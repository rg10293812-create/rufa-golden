تم تحديث النظام حسب طلبك:

1) إدارة المستخدمين أصبحت إدارة الموظفين والصلاحيات.
2) حساب الدور القديم marketer يظهر الآن باسم موظف داخل النظام بدون تغيير قاعدة البيانات.
3) في الصفقات الخارجية تظهر أسماء الحسابات الموجودة في النظام لتقسيم نسب الموظفين.
4) النسبة المحفوظة في حساب الموظف تظهر كمرجع، وتستطيع تعديل نسبة كل موظف داخل الصفقة.
5) المشاهد لا يحصل على صلاحيات إضافة أو إدارة موظفين إلا إذا أعطيته صلاحية إدارة الموظفين صراحة.
