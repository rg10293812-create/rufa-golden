التعديل الجديد:
1) إضافة حفظ تلقائي لمسودة العقار على السيرفر كل ثانيتين أثناء الكتابة.
2) إذا طفى النظام أو أعاد التشغيل ترجع آخر مسودة عند فتح صفحة العقارات.
3) عند الضغط على حفظ العقار يتم حفظه نهائياً ومسح المسودة.
4) إضافة زر مسح المسودة إذا رغبت تبدأ من جديد.
5) إضافة استيراد جماعي للإعلانات عبر نسخ البيانات أو رفع CSV.

طريقة الاستيراد الجماعي:
كل سطر إعلان واحد بهذا الترتيب:
اسم العقار,الحي,السعر,النوع,حصري,المواصفات

مثال:
فيلا قرطبة,قرطبة,1700000,villa,حصري,4 ماستر + مجلس + صالة
شقة اليرموك,اليرموك,850000,apartment,,3 غرف + صالة

ملاحظة مهمة:
المتصفح يمنع حفظ الصور تلقائياً قبل الضغط على زر الحفظ لأسباب أمان. لذلك النصوص تحفظ تلقائياً، أما الصور فاضغط حفظ بعد اختيارها.
